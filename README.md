# Kinesio Fitt

Marketing site rebuild for [Kinesio Fitt](https://www.kinesiofittmason.com/) — a family-owned, full-service gym on the historic square in Mason, TX.

Single-page editorial homepage. Tailwind via CDN, no build step. Open `index.html` in a browser or run a local server.

## Run locally

```bash
python3 -m http.server 8910
# open http://localhost:8910/index.html
```

## Project context

See [`PROJECT.md`](./PROJECT.md) for the full brand system, file map, what's done, and what's next.

## Stack

- Plain HTML
- Tailwind (CDN)
- Space Grotesk + Inter + JetBrains Mono via Google Fonts
- Material Symbols icons
- Vanilla JS (modal, scroll reveal, nav shadow)
